# Work plan: what to do first, and what can run in parallel

All 165 task issues in order. Generated by `scripts/tasks.py` (titles in `scripts/titles_en.py`).

**How to read it**
- Sprints run in order, and inside a sprint the **steps** run in order.
- **Tasks in the same step don't depend on each other**: give them to different people at the same time.
- A step starts only when the tasks it needs (listed after «needs») are merged. Tasks from earlier sprints are assumed done.
- Several people? Each takes the next free task in the earliest step that still has open tasks.
