# ADR-0001 · TypeScript monorepo

**الحالة:** مقبول · 2026-10-28

**السياق:** المشروع فيه واجهة، وAPI، وجوبز، وقواعد بيزنس كتيرة ومتشابكة (كوميشن، SLA، حضور، KPIs) لازم تبقى واحدة في كل حتة. والديمو المعتمد مكتوب JavaScript.

**القرار:** كل حاجة TypeScript في ريبو واحد (pnpm workspaces + Turborepo). وقواعد البيزنس في `packages/domain`، والـ schemas المشتركة في `packages/contracts`.

**العواقب:** + القاعدة بتتكتب مرة واحدة، وتغيير الـ API والواجهة بيبقى في PR واحد، والأنواع بتمسك أي كسر في العقد بينهم. − الريبو محتاج أدوات (Turbo) والـ CI بيبني كل حاجة. **البديل اللي اترفض:** Laravel + Filament، أسرع في شاشات الأدمن، بس الواجهة محتاجة تكون مخصوصة زي الديمو، ومنطق الديمو JS.
