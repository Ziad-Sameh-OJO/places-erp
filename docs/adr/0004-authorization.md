# ADR-0004 · الصلاحيات

**القرار:** القاعدة واحدة في `packages/domain/permissions.ts`: أدوار مجمّعة، واستثناءات لكل شخص بتستبدل الدور في موديول، وكل action بيستلزم view، ونطاق بيانات. والـ API بيطبّقها بـ guards: مقفول بالافتراضي، و `@Requires` إجباري.

**ليه:** نفس السلوك اللي الكلاينت جربه في الديمو (مصفوفة 7 actions × 19 موديول)، ولو حد نسي يحط الصلاحية، الطلب بيترفض بدل ما يعدّي.
