# ADR-0002 · Modular monolith مش microservices

**الحالة:** مقبول · 2026-10-28

**السياق:** حوالي 40 يوزر، وآلاف الليدز، وفريق صغير.

**القرار:** API واحد (NestJS) متقسم موديول لكل جزء في الركوايرمنتس، و worker واحد للجوبز، وداتابيز واحدة بـ schema لكل مجال.

**العواقب:** + نشر بسيط، و transactions عادية بين الموديولات (مثلاً صفقة ← قفل وحدة)، وتكلفة استضافة قليلة. − لازم نلتزم بحدود الموديولات (ESLint + المراجعة). ولو موديول احتاج يتفصل بعدين، حدوده واضحة.
