# الانفنتوري

**كل يوم:** «مخزون الوحدات». ابدأ بالفلاتر «PDF مستني Confirm» و«محتاجة ابديت».

**أكتر حاجات هتعملها:**
1. **وحدة جديدة:** «وحدة جديدة» ← اسم المبنى، المساحة، الدور، التشطيب، السعر للمتر، الـ Agent، الـ Location ← «حفظ الوحدة». الكود والـ Total price بيتعملوا لوحدهم.
2. **قبل ما توصل للسيلز:** الوحدة الجديدة بتفضل «PDF مستني Confirm» ومش ظاهرة للسيلز لحد ما مدير الانفنتوري يعمل Confirm.
3. **ابديت مع المالك:** افتح الوحدة ← «تعديل البيانات» ← غيّر السعر أو «Last update». أي تعديل بيرجّع الـ PDF يستنى Confirm.
4. **تابات المساحات:** «عدّل تابات المساحات» تضيف أو تعدّل أو تشيل شريحة مساحة.
5. **وحدة مش متاحة:** «أرشفة» بدل المسح.
