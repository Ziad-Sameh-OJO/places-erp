# الـ HR

**كل يوم:** «الموارد البشرية ← حضور النهارده»: مين حضر ومين اتأخر ومين مابصمش، وخصومات اليوم.

**أكتر حاجات هتعملها:**
1. **الحضور:** لو الجهاز مش بيتسحب لوحده ← «رفع شيت البصمة». الأسامي اللي مش متطابقة ← «اربط بموظف» مرة واحدة. اليوم الكامل محتاج «Confirm خصم يوم». لو الجهاز كان واقف ← «سجّل اليوم».
2. **الإجازات والـ Excuse:** تاب «الإجازات» ← اللي الـ TL وافق عليه ← «سجّل» أو «أكّدي». «أرصدة الإجازات» للرصيد.
3. **الجزاءات والـ 1-to-1:** «الجزاءات و1-to-1» ← «اعتمد» أو «ارفض» الجزاء المقترح. الـ 1-to-1 بيتحفظ في فايل الموظف، وحل الـ HR بييجي عليه Alarm.
4. **آخر الشهر:** تاب «التوفير» ← راجع الخصومات ← «اعتمد الخصومات وابعتها للمالية». وراجع الموظف المثالي.
5. **فايل الموظف:** تاب «الموظفين» ← المرتب، الشرايح، رصيد الإجازات، المواعيد الخاصة. التعديل بيوصل المالية على طول.
