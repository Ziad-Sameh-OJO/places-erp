# الأوبريشن (Sales Admin)

**كل يوم:** «العملاء المحتملين» ← «طلبات مستنية الأوبريشن»، وتابع الليدز اللي ملهاش سيلز والـ Draft.

**أكتر حاجات هتعملها:**
1. **تدخّل ليد:** «ليد جديد» ← الاسم والموبايل والـ channel والـ area ← «التوزيع (حسب الـ area)» ← «حفظ الليد». السيستم بيوصّله للسيلز اللي عليه الدور.
2. **تقرر في عميل مكرر:** «طلبات مستنية الأوبريشن» ← «قرّري» ← اختار لكل خانة القيمة اللي تفضل، والليد يفضل عند مين ← «احفظ القرار».
3. **توزّع ليد مالوش سيلز:** لو المنطقة مالهاش سيلز، الليد بيوصلك ← افتحه ← «حوّل لـ» السيلز ← «حوّل».
4. **تتابع بالفلاتر:** فلتر بالـ channel والكامبين والسيلز والمنطقة، واحفظ الفلتر كعرض ترجعله كل يوم.
5. **الـ Draft:** الليدز اللي اتسحبت من غير أكشن بتروح الـ Draft؛ وزّعها من هناك لو الصلاحية عندك.
