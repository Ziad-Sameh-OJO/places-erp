# المالية (المحاسب)

**كل يوم:** «المالية ← Dashboard ← مستنيك النهارده»: المرتبات والفواتير الثابتة والبنود اللي عدّت البادجت. وبعدين «الخزن والحركات».

**أكتر حاجات هتعملها:**
1. **إذن صرف / توريد / تحويل:** «الخزن والحركات» ← الإذن ← سجّله. كل إذن بيعمل قيده لوحده وبيغيّر الأرصدة، واطبعه PDF بالختم والإمضا.
2. **العهد والسلف:** إذن «عهدة» أو «سلفة موظف»، والعهدة بتتقفل بـ «تسوية». السلفة بتتخصم مع المرتبات.
3. **طلبات المشتريات والمطالبات:** «طلبات مشتريات مستنية الصرف» ← «اصرفها». «المطالبات» ← اعتمد، ارفع الفاتورة الإلكترونية، وسجّل التحصيل بالإيصال.
4. **آخر الشهر:** «المرتبات» ← «اصرف المرتبات كلها» (بعد اعتماد الـ HR) ← «القيود» ← «اقفل الشهر».
5. **التقارير:** «قايمة الدخل» و«الميزانية العمومية» و«كشف حساب» لأي حساب من «شجرة الحسابات»، و«البادجت» لكل بند.
