# المشتريات ومدير المكتب

**كل يوم:** «المشتريات»: الطلبات «مستنية موافقة» و«جاهزة للصرف»، ورصيد العهدة.

**أكتر حاجات هتعملها:**
1. **طلب شراء / دفع:** «طلب شراء / دفع» ← الحاجة، المبلغ، البند، المورد، الفاتورة أو عرض السعر ← «ابعت للموافقة». فوق 10,000 لازم إيصال أو عرضين أسعار.
2. **بعد الموافقة:** اصرف، وبعدين «التسوية» بالمبلغ الفعلي والإيصال ← «اتسوّى · ابعته للمالية». لو المبلغ اتغير الطلب بيرجع للموافقة.
3. **تتابع البادجت:** «Budget لكل بند» يقولك اتصرف كام وفاضل كام قبل ما تطلب.
4. **أصول المكتب (مدير المكتب):** «سجل أصول المكتب» ← «أصل جديد» وعلّم «اتراجع» كل شهر أو «محتاج صيانة».
5. **جدول الـ Office Boys (مدير المكتب):** «منطقة جديدة» بالمسؤول والمواعيد، وعدّلها لما تتغير.
