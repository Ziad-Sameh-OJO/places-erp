# الركوايرمنتس · كل المصادر

المرجع الحي هو **ملف المتطلبات على places.reca-tech.com** (14 موديول، كل سؤال واتجابته). النسخة اللي هنا متصدّرة منه، وكل مصدر جه منه حاجة محفوظ تحت.

| الملف | إيه هو |
|---|---|
| `requirements.json` · `requirements.md` | **أحدث نسخة** من ملف المتطلبات (29/10 · M-01 … M-14 · 100%)، متصدّرة من الموقع. الـ `.md` بيتولّد بـ `python3 scripts/requirements_md.py` |
| `CHANGES.md` | اللي اتغير من النسخة القديمة (25/10): 6 موديولات جديدة و60 إجابة اتعدّلت. كل حاجة فيه اتوزّعت على كروت `docs/roadmap.md` |
| `modules-draft.md` | أول تقسيم للمتطلبات على الموديولات، من محضر الاجتماع وصور الملاحظات (فيه ⚠️ على الكلام اللي مش واضح) |
| `sources/meeting-minutes.pdf` | محضر الاجتماع الأول وتوثيق المتطلبات |
| `sources/clarification-questions.md` | الأسئلة اللي اتبعتت للكلاينت بعد الاجتماع |
| `sources/answers-leads-telesales.md` | إجابات الكلاينت: التوزيع، والمناطق، والـ SLA، والـ No Answer |
| `sources/answers-telesales-voice.md` | فويس: الـ Telesales تشوف إيه من الليدز |
| `sources/answers-transactions-voice.md` | فويسات 27/10: الـ Transactions، والـ Buyer/Seller، والتارجت، والكوميشن |
| `sources/answers-finance-dashboard.md` | طلب إضافة: الخزن والبنوك وسلف الموظفين على داشبورد المالية |
| `sources/inventory-unit-fields.md` | حقول الوحدة من منار: مين بيدخلها، وإجباري ولا لأ، ونوعها |
| `sources/kpis-q4-2026.md` | ملف مؤشرات الأداء Q4 2026 (نص الـ PDF) |
| `sources/answers-kpis.md` | إجابات الكلاينت على أسئلة الـ KPIs (28/10) |
| `sources/requirements-export-v2.json` | نسخة قديمة من ملف المتطلبات (25/10، فيها 8 موديولات بس) · للتاريخ |
| `images/team-leaders-and-teams.png` | الـ 4 Team Leaders وفرقهم A–D |
| `images/sales-kpi-card.png` | كارت KPIs السيلز (التارجت 40%، والباقي 10% لكل بند) |
| `images/ideal-employee.jpg` | قاعدة الموظف المثالي وصندوق الفريق |
| `images/handwritten-*.{jpg,png}` | صور ملاحظات الكلاينت بخط الإيد (التسويق ورحمة، والـ Achievements، والليدز والانفنتوري) |

**الديمو** اللي الكلاينت شافه موجود في `demo/`: `design-2` هو الديمو الوحيد والمرجع (التصميم الأول اتشال بعد ميتنج 4 نوفمبر). افتح `demo/index.html` في المتصفح.
