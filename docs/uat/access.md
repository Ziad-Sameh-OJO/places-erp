# UAT · الأدوار والصلاحيات والـ Audit Log (M-09)

الشاشة: «الأدوار والصلاحيات».

### 1. حساب جديد وتفعيله
- **مين:** الـ Super Admin
- **الخطوات:** المستخدمين ← «+ حساب جديد» ← الاسم، الإيميل، الدور الأساسي، الـ Team Leader أو المدير المباشر ← «اعمل الحساب وابعت التفعيل». الموظف يفتح لينك الإيميل ويعمل باسورد.
- **المتوقع:** «الحساب اتعمل · اتبعت إيميل التفعيل»، حالته «مستني التفعيل» وبعدين «شغال»، وبيتعمله فايل موظف في الـ HR.
- ☐ تمام · ملاحظات: ____

### 2. دور جديد ومصفوفة الصلاحيات
- **مين:** الـ Super Admin
- **الخطوات:** الأدوار ← «نسخة» من دور موجود ← غيّر الاسم ونطاق البيانات (بتاعه بس / فريقه / قسمه / الكل) ← في المصفوفة شيل «يعدّل» من موديول ← حفظ.
- **المتوقع:** «اتحفظ · بيتطبّق فوراً». حد على الدور ده يدخل: الموديول «عرض بس»، والداتا في حدود النطاق بس.
- ☐ تمام · ملاحظات: ____

### 3. استثناء لشخص
- **مين:** الـ Super Admin
- **الخطوات:** المستخدمين ← افتح شخص ← «استثناءات» ← ادّيله صلاحية مش في دوره ← «تمام». بعدين «رجّع زي الدور».
- **المتوقع:** الصلاحية بتشتغل له لوحده وبترجع لما ترجّعها.
- ☐ تمام · ملاحظات: ____

### 4. إيقاف حساب وتغيير الباسورد
- **مين:** الـ Super Admin
- **الخطوات:** «إيقاف» حساب ← جرّب تدخل بيه. بعدين «تفعيل». و«تغيير الباسورد» لحساب تاني.
- **المتوقع:** الموقوف مايقدرش يدخل. لينك تغيير الباسورد بيوصل على إيميله.
- ☐ تمام · ملاحظات: ____

### 5. منع الوصول
- **مين:** السيلز
- **الخطوات:** جرّب تفتح «المالية» أو «الأدوار والصلاحيات» من اللينك مباشرة.
- **المتوقع:** مش ظاهرة في المنيو، والصفحة مابتجيبش أي داتا.
- ☐ تمام · ملاحظات: ____

### 6. الـ Audit Log وتصدير الصلاحيات
- **مين:** الـ Super Admin
- **الخطوات:** Audit Log ← فلتر بموديول وشخص وفترة. المستخدمين ← «مين عنده أنهي صلاحية.xlsx».
- **المتوقع:** كل تعديل من السيناريوهات اللي فاتت ظاهر (مين، إمتى، قبل/بعد، الجهاز)، والإكسيل بينزل.
