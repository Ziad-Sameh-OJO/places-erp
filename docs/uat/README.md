# سيناريوهات تجربة الكلاينت (UAT)

سيناريو مكتوب لكل موديول خلص على `main`. الجلسة: كل قسم يدخل على نسخة التجربة بحساب الدور المكتوب، ينفّذ الخطوات، ويعلّم ☐ لو النتيجة زي «المتوقع». أي حاجة مختلفة تتكتب في «ملاحظات» وتتفتح issue (bug أو feature) في milestone الـ UAT.
