# UAT · المستندات والختم والإمضا

الشاشة: «الإعدادات ← قوالب المستندات» و«الختم والإمضا».

### 1. رفع الختم والإمضا
- **مين:** الـ Super Admin (وجرّب بحساب المحاسب)
- **الخطوات:** «الختم والإمضا» ← «ارفع» صورة PNG أو JPG للإمضا وللختم.
- **المتوقع:** «اترفع · هيظهر على كل الملفات». بحساب تاني: «الختم والإمضا بيرفعهم الـ Super Admin بس». صورة بايظة: «الصورة مش سليمة».
- ☐ تمام · ملاحظات: ____

### 2. الجهات واللوجو وبيانات البنك
- **مين:** الـ Super Admin
- **الخطوات:** «قوالب المستندات» ← الجهة ← «غيّر اللوجو» واكتب البنك واسم ورقم الحساب ← احفظ.
- **المتوقع:** اللوجو فوق المطالبة والإيصال، وبيانات البنك مكتوبة في المطالبة.
- ☐ تمام · ملاحظات: ____

### 3. تعديل قالب
- **مين:** الـ Super Admin
- **الخطوات:** «قالب المطالبة» ← عدّل العنوان والنص والختام ← «شوف شكلها» ← احفظ. بعدين «رجّع الافتراضي».
- **المتوقع:** «اتحفظ القالب» والكلمات اللي بين الأقواس بتتملي من البيانات. الافتراضي بيرجع زي ما كان.
- ☐ تمام · ملاحظات: ____

### 4. الملف الطالع
- **مين:** المحاسب
- **الخطوات:** اعمل مطالبة وإيصال وإذن صرف (من المالية) ونزّل الـ PDF.
- **المتوقع:** كل PDF عليه اللوجو والختم والإمضا ونص القالب الجديد.
